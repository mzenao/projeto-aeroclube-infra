# Backend Laravel (preparação)

Esta pasta reserva o limite do backend futuro. Instale uma aplicação Laravel aqui quando a persistência/API for necessária. O frontend deverá trocar os adapters em `resources/js/adapters` e configurar `VITE_API_BASE_URL`, sem mudanças nos componentes.

Responsabilidades previstas: autenticação, API interna, sincronização, PostgreSQL/SQLite e integrações.
